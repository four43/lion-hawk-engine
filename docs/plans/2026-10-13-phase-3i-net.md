# Phase 3i: the World `net` part (implementation plan)

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task by task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** entities with a `net` part replicate on their own through the existing codec, store and tracker (N-9). Non-authority peers run them in one of three remote modes:
- `driven`: a solid dynamic body that plays the owner's batched inputs, corrected by snap or nudge (N-12…N-16);
- `proxy`: a kinematic body;
- `view`: a pool pose only.

Proxy and view follow the interpolation buffer or the forecast (D8). Tunables are live (N-17), `F.body()` is added (N-8), `netId` is separate from `e.id` (D7), and `mp()` gains `drop`, `blackout` and `diverged` (T-11). The part must be able to host Tractor Pickup's four kinds.

**Architecture:**
- `installNet(engine)` makes one controller per engine. It is installed by the World install (integrator request 1) or by a game's `setup`; the call is idempotent.
- The controller registers:
  - built-in `net.open`, `net.peer` and `net.frame` handlers through 3c's `engine.builtin` seam;
  - `lh.net.recv` in stage `pre`, before `lh.scene`, for remote poses, input playout and nudges;
  - a send clock on `engine.onStep`, registered before any port, so the port drains what it queued.
- The controller is `world.net` on every World it sees. A new World, or a new `world.serial`, resets the per-World state.
- `src/sim/net/replicate.js` reads and applies records. `src/sim/net/remote.js` holds the remote-mode math. Both are plain functions over objects made at spawn.
- `src/sim/replica.js` and `src/sim/forecast.js` stay unchanged. `src/sim/interp.js` gains a non-allocating `sampleInto`.

**Tech Stack:** plain ES modules; `@dimforge/rapier3d-compat` 0.21, injected (D9; only tests import it); `node:test`; the engine's `mp()` over the in-memory hub.

**Spec:** `docs/spec.md` plus `docs/plans/2026-10-13-phase-3-overview.md`. This plan implements N-8 (`F.body`), N-9, N-10, N-11 (send clock per kind), N-12…N-17, E-7 (guest guard), D7, D8 and T-11 (rest). It follows overview §4.11, which this plan produces, and builds on §4.4 and §4.5, which 3c produces.

**Binding user decisions (2026-10-13):**
- Other players' tractors in Tractor Pickup are **solid and collide** with each other. Honking on contact is game-side. `driven` is therefore fully specified and tested here, including a two-sim bump test where a local body and a driven remote body collide.
- **NET_VERSION 4 is approved.**

## NET_VERSION 4 and old devices (overview R5, §8)

- **Decision:** phase 3 forces Tractor's `NET_VERSION` to 4. The wire changes because `F.body()` drops `dirt` (it moves to its own field) and because driven kinds send batched inputs (`input: { s, list }`).
- `NET_VERSION` stays the game's constant. The engine's `{ engine, game, schema }` join check (N-6) is unchanged; this plan does not touch it.
- **Old devices:** Handshake keys rooms by app version, so a 1.8.0 device and a 1.9.0 device never see each other's rooms. A room code typed across versions fails with Handshake's version refusal. Tractor shows "This room is running a different version. Reload to update."; 3l adds the message if it is missing and checks it by hand (R5 c).
- This plan only makes the engine side able to carry Tractor's kinds. The version bump, the bump test on Tractor and the two-page `peers()` test belong to 3l.

```js
// src/defs/fields.js
// Field types and kinds for replicated objects (N-8, N-11), moved from Tractor Pickup's src/net/replica.js (M-22). Plain data: src/sim/replica.js packs them.
// Phase 3i: F.body() (N-8) and the kind's net-part options (N-9, N-12..N-17, D8): remote, follow, tune, send and the spawn hooks.
// Existing kinds keep their wire bytes; only a driven kind sends its `input` as { s, list } (N-13).
const boolsOf = fields => Object.keys(fields).filter(k => fields[k].t === 'bool');
export const F = {
  bool: () => ({ t: 'bool' }), // the bools of one obj share a flags byte (at most 8)
  uint: (bytes, max = 2 ** (8 * bytes) - 1, min = 0) => { if (![1, 2, 4].includes(bytes)) throw new Error('bad uint width ' + bytes); if (!Number.isInteger(min) || !Number.isInteger(max) || min > max) throw new Error(`bad uint range ${min}..${max}`); return { t: 'uint', bytes, max, min }; }, // min: encode throws below it, decode drops (N-8)
  id: () => ({ t: 'id' }), // u16; null travels as 0xffff
  oneOf: list => ({ t: 'enum', list }), // u8 index
  fixed: (lo, hi, step) => ({ t: 'fixed', lo, hi, step, n: Math.round((hi - lo) / step) }), // u16 steps from lo; values are clamped into lo..hi
  angle: () => ({ t: 'angle' }), // u16 over a full turn
  quat: () => ({ t: 'quat' }), // 4 x i16, normalized on decode
  obj: fields => { const bools = boolsOf(fields); if (bools.length > 8) throw new Error('too many bools: ' + bools.length); return { t: 'obj', fields, bools }; },
  list: (of, max, min = 0) => ({ t: 'list', of, max, min }), // u8 count
  // an action snapshot (N-8): axes as i16/32767 in the map's key order, then the buttons as flags (8 per byte); decodes to { axis: number, button: boolean }
  actions: map => {
    const names = Object.keys(map), axes = names.filter(n => map[n].kind === 'axis'), buttons = names.filter(n => map[n].kind === 'button');
    if (axes.length + buttons.length !== names.length) throw new Error('F.actions: every action must be axis() or button()');
    return { t: 'actions', names, axes, buttons };
  },
  // N-8: one body's { p, q, v, w } at Tractor Pickup 1.8.0's precision: p.x/p.z in 1/64 m over ±range, p.y in 1/256 m over ±height,
```

```js
// src/sim/net/replicate.js
// The net part's records (N-9): the default record read from an entity (F.body() fields from Rapier, or the pool for a bodiless
// entity; everything else from e[k]), the default apply written back, and the owner's input ring for driven kinds (N-13).
// Plain functions over objects made once per entity: nothing here allocates per step (R-8). Sim-pure.
import { INPUT_BATCH } from '../../defs/fields.js';

const v3 = () => ({ x: 0, y: 0, z: 0 });
// Contract issue 1: the entity an F.body() field reads. 'body' is the entity itself; any other field names a linked entity e[field]
// (Tractor's trailer and wagon), spawned with it and despawned with it.
export const bodyEntity = (e, field) => field === 'body' ? e : e[field];
export const zeroActions = f => { const o = {}; for (const n of f.axes) o[n] = 0; for (const n of f.buttons) o[n] = false; return o; };
// axes as numbers, buttons as booleans; a missing source value is 0 / false
export function copyActions(f, src, out) {
  for (let i = 0; i < f.axes.length; i++) { const n = f.axes[i], x = src?.[n]; out[n] = Number.isFinite(x) ? x : 0; }
  for (let i = 0; i < f.buttons.length; i++) { const n = f.buttons[i]; out[n] = !!src?.[n]; }
  return out;
}
// one record object per entity, made at its first send or receive and reused for every send after
export function newRecord(k) {
  const r = {};
  for (const name of Object.keys(k.fields)) {
    if (k.fields[name].body === true) r[name] = { p: v3(), q: { x: 0, y: 0, z: 0, w: 1 }, v: v3(), w: v3() };
    else if (name === 'input' && k.input) r[name] = k.remote === 'driven' ? { s: 0, list: [] } : zeroActions(k.input);
    else r[name] = undefined;
  }
  return r;
}
// one body's state into out = { p, q, v, w }: from Rapier (its per-call vectors are tolerated, §7.3), or the pool pose of a bodiless entity, still
export function readBody(ent, out) {
  if (ent?.body) {
    const b = ent.body, t = b.translation(), q = b.rotation(), v = b.linvel(), w = b.angvel();
    out.p.x = t.x; out.p.y = t.y; out.p.z = t.z; out.q.x = q.x; out.q.y = q.y; out.q.z = q.z; out.q.w = q.w;
    out.v.x = v.x; out.v.y = v.y; out.v.z = v.z; out.w.x = w.x; out.w.y = w.y; out.w.z = w.z;
  } else if (ent?.xf) {
    const P = ent.xf.p, Q = ent.xf.q;
    out.p.x = P.x; out.p.y = P.y; out.p.z = P.z; out.q.x = Q.x; out.q.y = Q.y; out.q.z = Q.z; out.q.w = Q.w;
    out.v.x = out.v.y = out.v.z = 0; out.w.x = out.w.y = out.w.z = 0;
  } else throw new Error(`net: an F.body() field needs an entity with a body or xf (entity ${ent?.id})`);
  return out;
}
// N-9: the default record. ring: the owner's input ring when the kind is driven, else null
export function defaultRecord(k, e, out, ring) {
  for (const name in k.fields) {
    if (k.fields[name].body === true) readBody(bodyEntity(e, name), out[name]);
    else if (name === 'input' && k.input) { if (ring) ring.fill(out.input); else copyActions(k.input, e.input, out.input); }
    else out[name] = e[name];
  }
  return out;
}
// N-9: the default apply: every field but the pose (the remote mode moves bodies and the pool) and a driven input (the queue plays it)
export function applyFields(k, e, rec) {
  for (const name in k.fields) {
    if (k.fields[name].body === true) continue;
    if (name === 'input' && k.input) { if (k.remote !== 'driven') copyActions(k.input, rec.input, e.input ??= zeroActions(k.input)); continue; }
    e[name] = rec[name];
  }
}
// N-13: the owner's last INPUT_BATCH inputs by owner step; fill(out) sets out.s (the newest step) and out.list (oldest first; the ring's objects)
export function createInputRing(f) {
  const slots = Array.from({ length: INPUT_BATCH }, () => ({ s: 0, v: zeroActions(f) }));
  let n = 0, head = 0; // head: the next slot written
  return {
    get size() { return n; },
    push(s, src) { const x = slots[head]; x.s = s; copyActions(f, src, x.v); head = (head + 1) % INPUT_BATCH; if (n < INPUT_BATCH) n++; },
    fill(out) {
      out.list.length = n;
      for (let i = 0; i < n; i++) out.list[i] = slots[(head - n + i + INPUT_BATCH) % INPUT_BATCH].v;
      out.s = n ? slots[(head - 1 + INPUT_BATCH) % INPUT_BATCH].s : 0; return out;
    },
    clear() { n = 0; head = 0; },
  };
}
```

```js
// src/sim/net/remote.js
// Remote entities (N-12..N-16): the driven actor's input queue, the latency rule, snapshot projection, snap-or-nudge, the nudge
// servo, and the pose writers for proxy (kinematic next pose) and view (pool). Every function writes into objects made at spawn.
import { extrapolate, newPose } from '../forecast.js';
import { qmul } from '../../core/math.js';
import { copyActions, zeroActions } from './replicate.js';

export const QUEUE = Object.freeze({ cap: 16, high: 4, keep: 2 }); // N-13: past `high` the queue drops to the newest `keep`
export const LEAD_MS = 250; // the longest projection (as FORECAST.horizon)
export const SHARED_MS = 1000; // an interp offset outside [0, SHARED_MS] means the two clocks are not shared: no projection (Contract issue 4)
export const MAX_ANGLE = Math.PI / 6; // N-14: 30 degrees

// N-13: one remote driven actor's inputs by owner step. offer(batch) takes a record's { s, list } (list[i] is owner step
// s - (len - 1 - i)); take(out) copies the oldest into out each local step, holds out when empty, and drops to the newest
// `keep` when more than `high` wait.
export function createInputQueue(f) {
  const slots = Array.from({ length: QUEUE.cap }, () => ({ s: 0, v: zeroActions(f) }));
  let head = 0, n = 0, last = -1, used = -1;
  return {
    get size() { return n; }, get used() { return used; }, get last() { return last; },
    offer(batch) {
      const len = batch.list.length;
      for (let i = 0; i < len; i++) {
        const s = batch.s - (len - 1 - i); if (s <= last) continue;
        if (n === QUEUE.cap) { head = (head + 1) % QUEUE.cap; n--; } // full: the oldest goes
        const x = slots[(head + n) % QUEUE.cap]; x.s = s; copyActions(f, batch.list[i], x.v); n++; last = s;
      }
    },
    take(out) {
      if (n > QUEUE.high) { head = (head + n - QUEUE.keep) % QUEUE.cap; n = QUEUE.keep; }
      if (!n) return false;
      const x = slots[head]; copyActions(f, x.v, out); used = x.s; head = (head + 1) % QUEUE.cap; n--; return true;
    },
    clear() { head = 0; n = 0; last = -1; used = -1; },
  };
}
// N-14: the one-way latency, from the interp offset (receiver clock - sender clock, least-delayed message). It is the latency only
// when both clocks are the same clock (mp, peers); otherwise the snapshot is used as it is.
export const latencyMs = offset => offset >= 0 && offset <= SHARED_MS ? Math.min(offset, LEAD_MS) : 0;
export const newTarget = () => { const t = newPose(); t.v = { x: 0, y: 0, z: 0 }; t.w = { x: 0, y: 0, z: 0 }; t.left = 0; return t; };
// N-14: a body snapshot { p, q, v, w } moved on by latMs, into the target t (velocity and spin kept)
export function project(rec, latMs, t) {
  extrapolate(rec, latMs / 1000, t);
  t.v.x = rec.v.x; t.v.y = rec.v.y; t.v.z = rec.v.z; t.w.x = rec.w.x; t.w.y = rec.w.y; t.w.z = rec.w.z; return t;
}
const ERR = { d: 0, angle: 0 };
export function poseError(p, q, t, out = ERR) {
  out.d = Math.hypot(t.p.x - p.x, t.p.y - p.y, t.p.z - p.z);
  out.angle = 2 * Math.acos(Math.min(1, Math.abs(q.x * t.q.x + q.y * t.q.y + q.z * t.q.z + q.w * t.q.w))); return out;
}
export const decide = (err, tune) => err.d < tune.snapAt && err.angle < MAX_ANGLE ? 'nudge' : 'snap';
const inv = { x: 0, y: 0, z: 0, w: 1 }, dq = { x: 0, y: 0, z: 0, w: 1 }, tmp = newPose();
// one nudge step (N-14): velocities = the target's + the error over the steps left (the error shrinks by (1 - 1/left) a step and is
// gone after `nudge` steps); then the target moves on by dt. Returns the steps left.
export function nudgeVelocity(c, p, q, dt, outV, outW) {
  const k = 1 / (c.left * dt);
  outV.x = c.v.x + (c.p.x - p.x) * k; outV.y = c.v.y + (c.p.y - p.y) * k; outV.z = c.v.z + (c.p.z - p.z) * k;
  inv.x = -q.x; inv.y = -q.y; inv.z = -q.z; inv.w = q.w; qmul(c.q, inv, dq);
  if (dq.w < 0) { dq.x = -dq.x; dq.y = -dq.y; dq.z = -dq.z; dq.w = -dq.w; }
  const s = Math.hypot(dq.x, dq.y, dq.z), m = s > 1e-9 ? 2 * Math.atan2(s, dq.w) / s : 2; // rotation vector = axis * angle (world frame)
  outW.x = c.w.x + dq.x * m * k; outW.y = c.w.y + dq.y * m * k; outW.z = c.w.z + dq.z * m * k;
  extrapolate(c, dt, tmp); c.p.x = tmp.p.x; c.p.y = tmp.p.y; c.p.z = tmp.p.z; c.q.x = tmp.q.x; c.q.y = tmp.q.y; c.q.z = tmp.q.z; c.q.w = tmp.q.w;
  return --c.left;
}
// proxy: the kinematic body's next pose (Rapier moves it in the step; lh.physics.read writes curr)
export function writeKinematic(ent, pose) { ent.body.setNextKinematicTranslation(pose.p); ent.body.setNextKinematicRotation(pose.q); }
// view: the pool's current slot (prev was copied by lh.world.swap)
export function writePool(ent, pose) {
  const P = ent.xf.p, Q = ent.xf.q; P.x = pose.p.x; P.y = pose.p.y; P.z = pose.p.z; Q.x = pose.q.x; Q.y = pose.q.y; Q.z = pose.q.z; Q.w = pose.q.w;
}
const conj = { x: 0, y: 0, z: 0, w: 1 }, jump = { x: 0, y: 0, z: 0, w: 1 };
// §4.9 / N-15: the drawn-pose jump of a snap, old - new (dq = old * new^-1); the view fades it over the kind's smoothMs
export function setNetFix(ent, oldP, oldQ, newP, newQ) {
  const f = ent.netFix ??= { seq: 0, dp: [0, 0, 0], dq: [0, 0, 0, 1] };
  f.dp[0] = oldP.x - newP.x; f.dp[1] = oldP.y - newP.y; f.dp[2] = oldP.z - newP.z;
  conj.x = -newQ.x; conj.y = -newQ.y; conj.z = -newQ.z; conj.w = newQ.w; qmul(oldQ, conj, jump);
  f.dq[0] = jump.x; f.dq[1] = jump.y; f.dq[2] = jump.z; f.dq[3] = jump.w; f.seq++; return f;
}
```

```js
// [T-11] mp(): headless peers over one in-memory hub (lion-hawk/net), each bound by a port, stepped in lockstep (2f T-E7, #75).
// Each w.step advances the hub clock by 1000/hz, ticks the hub (messages and transport events become commands, recorded when
// `record`), then steps every peer in order through its handle, so tapes record and a guest's tape replays alone (T-9, #78).
// N-4: the hub clock is the ports' clock and every engine's wall clock (a late peer starts at wall0 = hub.now).
// 3i: drop(peer) (gone for good, not stepped), blackout(seconds, { kinds }) (frames dropped at send, #94) and diverged({ agree })
// over `net` entities (each authority entity against its replica on every other live peer).
import { headless } from './headless.js';
import { createMemoryHub, createPort } from '../src/index.net.js';
import { rng } from '../src/core/rng.js';
import { createRegistry, decodeFrame, isFrame } from '../src/sim/replica.js';

export function mp(game, { peers = 2, link = {}, clock, record = false, seed = 1, argsOf = () => undefined, beforeStep, onWarn } = {}) {
  if (!game.net) throw new Error('mp: the game has no net config (defineGame({ net }))');
  if (!Number.isInteger(peers) || peers < 1) throw new Error('mp: peers must be a positive integer');
  const hz = game.sim.hz, hub = createMemoryHub({ rng: rng(seed).fork('mp.link').next, ...link }); // seeded jitter and loss
  const at = clock ?? (() => hub.now), list = [], reg = createRegistry(game.net.kinds, { maxSender: game.net.maxSender });
  const kindOf = (name, what) => { const k = reg.byName.get(name); if (!k) throw new Error(`mp: ${what}: unknown kind '${name}'`); return k; };
  let k = 0; // hub.now is k * 1000 / hz, the engines' own virtual-wall formula: peers created at the start are exact; a late peer's wall0 + m * 1000 / hz can be an ulp off (field note #93)
  const addPeer = () => {
    const index = list.length, name = index ? `guest${index}` : 'host';
    const h = headless(game, { seed, args: argsOf(index, name), record, wall0: hub.now });
    const net = index ? hub.join() : hub.host();
    const port = createPort(h.engine, { transport: net, role: index ? 'guest' : 'host', clock: at, onWarn: onWarn && ((kind, e) => onWarn(p, kind, e)) });
    const p = { index, name, h, engine: h.engine, net, port, dropped: false }; list.push(p); return p;
  };
  const one = inputs => {
    k++; hub.tick(k * 1000 / hz);
    for (let i = 0; i < list.length; i++) { // peers added by a beforeStep wait for the next step
      const p = list[i]; if (p.dropped) continue; beforeStep?.(p, i);
      const snap = typeof inputs === 'function' ? inputs(p, i) : inputs?.[i];
      if (snap != null) p.engine.input.set(snap);
      p.h.step(1);
    }
  };
  const peerOf = x => { const p = typeof x === 'number' ? list[x] : x; if (!p || !list.includes(p)) throw new Error('mp: no such peer'); return p; };
  const w = {
    hub, peers: list, get host() { return list[0]; }, get guests() { return list.slice(1); }, get now() { return hub.now; },
    get live() { return list.filter(p => !p.dropped); },
    step(n = 1, inputs) { for (let i = 0; i < n; i++) one(inputs); return w; },
    seconds: (s, inputs) => w.step(Math.round(s * hz), inputs),
    addPeer,
    settle(agree, { maxSeconds = 3 } = {}) { // steps until agree(w) returns [], at most maxSeconds; returns what is left
      let left = agree(w);
      for (let i = 0, n = Math.round(maxSeconds * hz); i < n && left.length; i++) { one(); left = agree(w); }
      return left;
    },
    // the peer vanishes (a crash, a closed tab): its port stops and the hub reports it gone (a host takes the room with it)
    drop(peer) {
      const p = peerOf(peer); if (p.dropped) throw new Error(`mp: ${p.name} is already dropped`);
      p.dropped = true; p.port.close(); hub.leave(p.net.id, 'dropped'); return w;
    },
    // replica frames sent in the next `seconds` are lost (all of them, or those carrying one of `kinds`); JSON messages pass (#94: decided at send)
    blackout(seconds, { kinds } = {}) {
      const names = kinds ? new Set(kinds.map(n => kindOf(n, 'blackout').name)) : null, until = hub.now + seconds * 1000, prev = hub.drop;
      hub.drop = (from, to, data, reliable) => {
        if (hub.now < until && isFrame(data)) {
          if (!names) return true;
          const f = decodeFrame(data, reg); if (f) for (const n of f.groups.keys()) if (names.has(n)) return true;
        }
        return prev ? prev(from, to, data, reliable) : false;
      };
      return w;
    },
    // agree: { kind: metres }. Every authority entity of those kinds (host kinds on the host, owner kinds on their owner) against the
    // same (kind, netId) on every other live peer: missing, or farther than the tolerance (position; data-only kinds: presence only)
    diverged({ agree } = {}) {
      if (!agree || typeof agree !== 'object') throw new Error('mp: diverged needs { agree: { kind: metres } }');
      const out = [], up = w.live;
      for (const [name, tol] of Object.entries(agree)) {
        const kd = kindOf(name, 'diverged');
        for (const a of up) {
          const net = a.h.world?.net; if (!net) continue;
          const ents = a.h.world.with('net');
          for (let i = 0; i < ents.length; i++) {
            const e = ents[i]; if (e.net !== name || net.remoteOf(e)) continue;
            if (kd.authority === 'host' ? net.role !== 'host' : !(net.self > 0 && e.netId === net.self)) continue;
            for (const b of up) {
              if (b === a) continue;
              const o = b.h.world?.net?.find(name, e.netId);
              if (!o) { out.push({ kind: name, netId: e.netId, peer: b.name, missing: true }); continue; }
              if (!e.xf || !o.xf) continue;
              const d = Math.hypot(o.xf.p.x - e.xf.p.x, o.xf.p.y - e.xf.p.y, o.xf.p.z - e.xf.p.z);
              if (!(d <= tol)) out.push({ kind: name, netId: e.netId, peer: b.name, d });
            }
          }
        }
      }
      return out;
    },
  };
  for (let i = 0; i < peers; i++) addPeer();
  return w;
}
```

## Contract issues

Each issue below states the smallest decision that works, as built in the tasks above. The controller reconciles them across plans.

1. **Multi-body actors (Tractor's train: tractor, trailer, wagon).** §4.11 shows one `body: F.body()`. **Decision:**
   - Any F.body field other than `body` reads and writes a linked entity `e[field]`.
   - `kind.spawn` must return a sub-desc per such field. The net part spawns the links, adds them with `world.add(e, field, link)`, calls `kind.spawned(e, world, rec)` (for joints), and despawns them with `e`.
   - Correction, interpolation and forecast run per body.
2. **Kind hooks and override signatures beyond §4.11:**
   - `spawn(rec, netId, world) → desc` is required for any kind whose replicas need a body or model; the default is `{}`;
   - `spawned(e, world, rec)`;
   - `record(e, out, world, base)`, where `base(e, out)` is the default record;
   - `apply(e, rec, world, s)`, where `s` is the interp sample `{ a, b, k }` for interp proxies and views, else `null`.

   F.body pose fields are always moved by the remote mode, never by `apply`.
3. **Driven wire form.** `input` travels as `{ s: u32 owner step, list: 1..8 snapshots }` (N-13). `driven` needs owner authority, `input: F.actions` and `body: F.body()`. It is the default only when all three are present; otherwise the default is `proxy`.
4. **"One-way latency (offset from interp)."** `interp.offset` is receiver clock − sender clock + latency, so it is the latency only when peers share a clock (`mp`, `peers`). **Decision:** `lat = offset ∈ [0, 1000] ms ? min(offset, 250) : 0`. On real devices with unrelated clocks, snapshots are used unprojected. This is a field note candidate and needs Tractor playtest feedback.
5. **`netFix` "on every correction".** It is set only on snaps. A nudge moves the body continuously and has no drawn-pose jump. The shape is §4.9's `{ seq, dp: [x, y, z], dq: [x, y, z, w] }`, where `dq = old · new⁻¹`.
6. **The `world.net` surface beyond `self`/`tunables`:**
   - `role`, `hostId`, `players` (Map peer → n);
   - `player(peer, n)`, the host's binding (#77);
   - `find(kind, netId)`, `remoteOf(e)`, `stats`, `attach(world)`, `guard(…)`;
   - `self` is validated, and the host is fixed at 1.

   Send clocks are per kind (`send.hz`, `send.key`). The frame `time` is `floor(engine.time.wall)`. A guest drops frames until `self` is set.
7. **Reserved kind fields under `net.world`.** Checked in `installNet`, not `kind()`:
   - the reserved names are `id`, `tags`, `model`, `colliders`, `xf`, `sockets`, `net`, `netId`, `netFix`;
   - `body` must be `F.body()`;
   - owner kinds may not have a field named `owner`.

   Tractor's `PLAYER.body` (a paint name) must be renamed by 3l.
8. **Assumed 3c shapes.**
   - `world.place(e, { at: [x, y, z] }, { q: [x, y, z, w], keep: true })` takes `q` as an array, like the spawn desc.
   - `engine.builtin(type, fn)` calls `fn(engine, data, ctx)`.
   - `world.add(e, name, entity)` accepts game-named parts.
   - `world.net` is a writable property.
9. **The room closing (`net.peer` `closed`).** The peer becomes `solo`. Replicated owner-kind entities are despawned. Host-kind replicas stay as plain local entities, and proxies stay kinematic; the game decides what happens next (Tractor's `goAlone`).
