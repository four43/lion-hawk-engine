## Running tests safely (since 2026-10-13)

A failing `assert.equal` on a DOM node, with about 31 test files running at once, exhausted memory twice (#103). Since then:
- every unit script runs `--test-concurrency=4`;
- agents run suites in a `systemd-run` scope capped at 1–4 GB, with a node heap limit below the cap, so a runaway dies inside node rather than triggering KDE low-memory notices;
- browser suites run one at a time.

Peaks now: the workspace suite about 1.2 GB, each browser suite about 1.1 GB.
