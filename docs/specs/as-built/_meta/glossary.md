# Glossary

One term for each concept in all specs. Writers use the **term** exactly and do not use the synonyms after "Not:". If a word has two meanings in the code, the glossary gives each meaning a qualified term (for example "replica frame" and "frame").

## Engine and loop

- **engine** — the object that `createEngine` returns. It owns the loop, scenes, commands, input, events and the World seat. Not: game instance, runtime. [src/core/engine.js:1]
- **game** — the frozen definition that `defineGame` returns. Not: game spec, config. [src/core/engine.js:1]
- **sim** — code that runs headless in Node and in the browser. Sim code imports no three.js, no DOM, no view module and no wall clock. Not: simulation layer, core layer. [src/index.sim.js:1]
- **view** — browser-only code. Also the object passed to view halves. Not: client, front end. [src/index.view.js:1]
- **sim-pure** — describes a module that obeys the sim rule and gets Rapier only by injection. Not: headless-safe, pure. [src/sim/world/world.js:4]
- **step** — one fixed sim update of `dt = 1/hz`. Not: tick, update, fixed update. [src/core/loop.js:4]
- **frame** — one browser animation frame. One frame runs zero or more steps. Not: render tick. [src/view/driver.js:3]
- **alpha** — the fraction of a step left in the accumulator, used to interpolate drawn poses. Not: render alpha, blend factor. [src/core/loop.js:10]
- **clamped frame** — a frame whose time exceeds `maxCatchUp` steps. The loop drops the extra time. Not: catch-up overflow. [src/core/loop.js:15]
- **stage** — a named phase of a step, run in fixed order: `input.apply`, `pre`, `physics.world`, `post`, `events.flush`. Not: phase, pass. [src/core/schedule.js:3]
- **system** — a named function added to a stage, ordered with `before` and `after`. Not: job, task, updater. [src/core/schedule.js:49]
- **wall clock** — `engine.time.wall` in ms. Real stamps set it. Without stamps, it is a virtual base plus steps × 1000/hz. Not: real time, injected clock. [src/core/engine.js:365]
- **rng stream** — a named, independent, seeded random sequence forked from the engine seed. Not: random fork, sub-rng. [src/core/engine.js:450]
- **event** — a typed object that sim code emits during a step. The engine delivers events in order at `events.flush` and keeps a ring log. Not: message, signal, notification. [src/core/events.js:6]
- **flags** — the frozen object parsed once from the URL query string (`?debug`, `?seed`, `?lh-test` and others). Not: query params, options. [src/core/flags.js:5]
- **frame ack** — a count of presented frames. With `acks: 'steps'` each step counts. With `acks: 'frames'` only `engine.presented()` counts. Not: present count. [src/core/engine.js:151]

## Scenes and loading

- **scene** — a named game state with sim hooks (`enter`, `exit`, `step`, `ui`) and scene presets. Not: level, screen, state. [src/core/engine.js:203]
- **main scene** — the scene at the bottom of the stack. Only the main scene owns a World. Not: base scene, root scene. [src/core/engine.js:203]
- **overlay** — a scene stacked above the main scene. Not: popup, modal, layer. [src/core/engine.js:401]
- **pausing overlay** — an overlay whose scene sets `pauses`. It freezes stages, and the scenes below it are **covered**. Not: pause menu. [src/core/engine.js:229]
- **covered** — describes a scene below a pausing overlay. The engine skips its step, its controls and its scene commands. Not: hidden, blocked. [src/core/engine.js:229]
- **transition** — a `go`, `overlay`, `close` or `jump` request. The engine queues transitions and never runs one inside another. Not: scene change, navigation. [src/core/engine.js:232]
- **scene preset** — a named function that puts a scene in a known state. `engine.jump` applies it. Not: preset (alone), fixture. [src/core/engine.js:410]
- **sim half** — the sim hooks of a scene. Not: scene logic. [src/core/engine.js:203]
- **view half** — the browser hooks of a scene (`enter`, `exit`, `frame`, `built`) declared with `defineView`. Not: scene view, renderer half. [src/view/boot.js:12]
- **load** — the loading state that `ctx.load` starts: hold, then build, then an optional settle. Not: loading screen, preload. [src/core/engine.js:176]
- **block** — a token from `engine.block(label)` or `view.wait` that holds a settling load until it is released. Not: lock, wait handle. [src/core/engine.js:438]
- **settled** — true when no block is pending, no load is active and no element is opening or closing. Not: idle, ready. [src/view/hook.js:37]

## Commands and input

- **command** — a typed, plain-JSON message queued for the sim and delivered at the next step's `lh.commands` system. Not: action, request, message, event. [src/core/engine.js:246]
- **built-in** — an engine command handler that runs before the game handler and is never covered (for example `lh.back`, `lh.open`, `lh.seat`, `net.*`). Not: system command, internal command. [src/core/engine.js:442]
- **reserved keys** — `from`, `at` and `reliable`. A port can set them on any command. Schemas must not declare them. Not: meta keys. [src/core/engine.js:21]
- **action** — a named game input, declared as `axis()` (−1 to 1) or `button()` (down, pressed, released). Not: control, binding, input (alone). [src/core/actions.js:6]
- **axis pair** — two axes merged per source by vector length, so both halves come from one device. Not: stick pair, mate. [src/core/actions.js:4]
- **input snapshot** — the merged action values that systems read for one step. Not: snapshot (alone), input state. [src/core/actions.js:21]
- **source** — a named per-device input layer, written with `input.device(values, source)`. Not: layer, input source, channel. [src/core/actions.js:59]
- **owed tap** — a rising edge not yet shown as a press. The input spreads owed taps over later applies, at most 3. Not: queued press, buffered tap. [src/core/actions.js:88]
- **input gating** — while a menu owns input, device sources are ignored. Buttons held at that time stay **latched** off until released. Not: input lock, suppression. [src/core/actions.js:25]
- **device** — a view module that reads hardware and writes a source (keyboard, gamepad, touch, custom kind). Not: input device, peripheral. [src/view/seats.js:222]
- **dead zone** — the magnitude below which an axis reads 0. The rest is rescaled to 0..1. Not: deadband, threshold. [src/view/gamepad.js:24]
- **map hook** — a device option `{ from, to, radial }` that turns a virtual stick pair into world-frame actions. Not: mapper, stick mapping. [src/view/mapPair.js:13]
- **raw dt** — the uncapped frame time passed to devices as the second `update` argument. Not: unclamped dt. [src/view/driver.js:19]
- **policy** — a headless input function `fn(h, i, scratch)` that returns one step's input. Not: autopilot, input script, bot. [src/core/policy.js:4]

## UI and menus

- **control** — a UI registry entry with role button, switch, choice, textbox or hold, and test id `<scene>.<id>`. Not: widget, element, button (for every role). [src/core/ui.js:15]
- **hold control** — a control that fires once after it is pressed for a set time. Not: long-press button. [src/core/ui.js:36]
- **slot adoption** — the DOM renderer uses game markup marked `data-lh-slot` as a control's element. Not: binding markup, hydration. [src/view/uiDom.js:56]
- **menu** — the topmost open overlay that declares `nav`. The main scene is never a menu. Not: nav scene. [src/core/nav.js:28]
- **nav options** — a scene's menu settings: `modal`, `initial`, `back`, `input`, `open`. Not: menu config. [src/core/nav.js:3]
- **open trigger** — a `nav.open` pad button or key that opens a menu from gameplay through `lh.open`. Not: menu hotkey. [src/view/menuNav.js:116]
- **pad edges** — the allocation-free reader that gives one direction per push and pressed, released and down per button. Not: edge detector. [src/view/padEdges.js:20]
- **pad family** — the pad brand class `xbox`, `ps`, `deck` or `generic`. Not: pad type, controller brand. [src/view/padEdges.js:11]
- **glyph role** — the meaning of an input prompt (`confirm`, `back`, `menu`, `move`, `prev`, `next`). Not: button icon. [src/kits/glyphs/view.js:7]
- **glyph family** — the icon set for the last input: a pad family, or `keys`, `pointer`, `touch`. Not: icon theme. [src/kits/glyphs/view.js:19]

## Players and seats

- **seat** — a local player slot on one page, numbered 0..15. Seat 0 never leaves. Not: local player, slot, lp (in prose). [src/core/controllers.js:85]
- **controller** — the sim object for one seat or bot. A controller has its own input and drives one pawn. Not: player controller, agent. [src/core/controllers.js:2]
- **bot** — a controller with no seat, driven by game code. Not: AI controller, NPC. [src/core/controllers.js:2]
- **pawn** — the entity that a controller drives. **possess** — to make a controller drive a pawn. Not: avatar, character, actor. [src/core/controllers.js:31]
- **player number** — a player's identity, 1..255, on the wire and in the roster. Seat 0 of the host is player number 1. Not: player id, number (alone), slot. [src/core/players.js:49]
- **roster** — `engine.players`: one entry per active or inactive player number, in number order. Not: player list, player array. [src/core/players.js:38]
- **game state** — `engine.gameState`, one object of game fields that the host replicates. Not: match state, global state. [src/core/players.js:9]
- **away** — a player flag set while the player's peer is away. **inactive** — a player flag set while the peer is gone and the player waits for rejoin. Not: idle, disconnected. [src/core/players.js:60]
- **pairing** — giving an unpaired device to a seat on the device's first press. Not: join (for devices), binding. [src/view/seats.js:364]
- **mask** — buttons held at pairing are hidden from bindings until released. Not: suppress. [src/view/seats.js:176]
- **lost** — describes a pad whose slot emptied, disconnected or changed id. **regain** — a device of the same kind returning to a seat that waits for a lost device. Not: dropped, reconnected. [src/view/seats.js:284]
- **mapping context** — named default bindings per device kind (pads by match, keys per scheme, touch factory). Not: input map, binding set, profile. [src/view/contexts.js:33]
- **context stack** — the per-seat list of mapping contexts by priority. Not: binding stack. [src/view/seats.js:192]
- **scheme** — a named keyboard binding set. `all` is the default keyboard device on seat 0. Not: layout, keymap. [src/view/seats.js:450]
- **profile** — named binding overrides saved in localStorage under `lh.bindings.<game>.<profile>`. Not: save, preset. [src/view/profiles.js:20]
- **haptics stop** — a zero effect plus `reset()`, sent at once and for `STOP_FRAMES` frames. The zero effect is a zero trigger-rumble on a pad whose `effects` lists `trigger-rumble`, and a zero dual-rumble on other pads. Not: rumble cancel. [src/view/haptics.js:16]

## World and physics

- **World** — the container for one main scene's entities and its `RAPIER.World`. Capitalized. Not: world (lower case for this concept), level, space. [src/sim/world/world.js:47]
- **World seat** — the engine slot that holds the current main scene's World. Not: world holder. [src/sim/world/install.js:19]
- **entity** — a plain object with a numeric `id`, a `tags` Set and optional parts. Not: object, actor, game object, node. [src/sim/world/world.js:174]
- **part** — a named property on an entity that queries match. Some parts are fixed after spawn. Not: component. [src/sim/world/world.js:22]
- **spawn descriptor** — the object given to `world.spawn`. Not: prefab, template, spawn options. [src/sim/world/world.js:20]
- **query** — the live, cached, id-ordered list that `world.with` returns. Not: view, filter, selection. [src/sim/world/world.js:268]
- **transform pool** — the shared `Float64Array` with 14 floats per pool slot: prev pose, then curr pose. Not: pose buffer. [src/sim/world/pool.js:13]
- **pool slot** — an entity's index in the transform pool, given lowest-free-first. Not: slot (alone), seat. [src/sim/world/pool.js:20]
- **prev** and **curr** — the two pose halves of a pool slot: the previous step and the current step. Not: old and new, last and next. [src/sim/world/pool.js:5]
- **swap** — copy curr into prev for every live pool slot at the start of a step. Not: flip, rotate. [src/sim/world/pool.js:49]
- **xf** — an entity's frozen accessor `{ p, q, slot }` for its current pose. Not: transform object. [src/sim/world/pool.js:61]
- **part pose** — a per-part pose in `partXf`, written by sim code. Not: bone, sub-transform. [src/sim/world/world.js:85]
- **place** — move an entity and its body together and write both prev and curr. Not: teleport, set position. [src/sim/world/place.js:19]
- **socket** — a named attachment point (`sock-<name>` node) in body space. Not: attach point, mount point, empty. [src/sim/world/place.js:52]
- **collision group** — one of at most 16 named bits. The Rapier mask is `membership << 16 | filter`. Not: layer, collision layer. [src/sim/physics/groups.js:23]
- **combine rule** — the Rapier coefficient rule: friction Multiply, restitution Max on engine colliders. Not: mixing rule. [src/sim/physics/colliders.js:46]
- **mass scale** — the factor that scales every collider density so a body weighs `body.mass`. Not: density multiplier. [src/sim/world/world.js:199]
- **heightfield** — a bodiless ground entity made from row-major heights. Not: terrain mesh (in sim). [src/sim/physics/heightfield.js:5]
- **joint** — a Rapier impulse joint between two entities, freed when either despawns. Not: constraint, hitch. [src/sim/world/world.js:350]
- **contact event** — the event `{ a, b, materials, impulse, point }` from a Rapier contact-force event. Not: collision event, hit. [src/sim/physics/events.js:24]
- **sensor event** — the event `{ sensor, other, on }` from a collision on a sensor collider. Not: trigger event. [src/sim/physics/events.js:27]
- **digest** — an FNV-1a hash over entity ids, curr poses and dynamic velocities as float64 bits. Not: world checksum. [src/sim/world/world.js:427]
- **serial** — a process-wide World number, renewed on clear and dispose. Not: generation, version. [src/sim/world/world.js:19]

## Materials and assets

- **material** — a registry entry with blocks such as `look`, `phys`, `tire`, `coverage`, `sound`, `fx`. Not: surface, physical material. [src/defs/materials.js:41]
- **material registry** — the frozen result of `defineMaterials`. Not: material table, material library (for the game result). [src/defs/materials.js:1]
- **base library** — the 18 built-in materials merged first. Not: default materials. [src/defs/materials.base.js:7]
- **material pair** — the ordered contact resolution between two materials (friction, restitution, tyre, sound, fx). Not: surface pair, contact pair. [src/defs/materials.js:176]
- **registry hash** — the 8-hex hash of physics-relevant material values. Baked sidecars must match it. Not: materials hash, material checksum. [src/defs/materials.js:198]
- **paint slot** — a `paint-<slot>` material id. Colliders take the paint base material, and the view colours it per entity or per instance. Not: paint material, color slot. [src/defs/materials.js:77]
- **coverage** — per-entity dirt, rust, snow, mud and wet levels 0..1. Not: wear, grime, weathering. [src/view/materials/chunks.js:29]
- **sidecar** — the baked physics data for one model: parts, colliders, mass, sockets, bounds. Not: physics metadata, phys entry. [src/defs/sidecar.js:75]
- **phys.json** — the baked file with every sidecar, the engine version and the registry hash. [src/defs/sidecar.js:120]
- **manifest** — the baked `manifest.json` that maps model keys to GLB and anim table paths, sizes and hashes. Not: asset index. [tools/bake/write.js:33]
- **bake** — the offline step that turns glTF sources into optimised GLBs, sidecars and anim tables. Not: compile, export, import. [tools/bake/index.js:75]
- **anim table** — baked clips sampled at a fixed fps into 12-float model-space matrices per part and socket. Not: baked animation, animation texture. [tools/bake/animTable.js:36]
- **template** — a loaded and compiled model (`{ scene, clips, anim, sockets }`) that instances clone. Not: prototype, prefab. [src/view/assets/index.js:33]
- **shading tier** — `physical`, `standard` or `lambert`: the three.js base material class for compiled materials. Not: quality level. [src/view/materials/compiler.js:10]
- **shader feature** — a compile-time define plus shader patch (`COVERAGE`, `FUR`, `SUBSURFACE`, `WIND`, `PAINT`). Not: shader option, effect. [src/view/materials/chunks.js:8]
- **depth twin** — a `MeshDepthMaterial` that repeats a material's vertex displacement in the shadow pass. Not: shadow material. [src/view/materials/compiler.js:258]
- **warm** — compile every shader program during loading so the first draw does not stall. Not: precompile, prime. [src/view/render/hygiene.js:54]

## Rendering and view sync

- **gfx** — the renderer bundle `{ renderer, scene, camera, post, render, lights, ... }` that boot exposes as `view.gfx`. Not: graphics context. [src/view/render/renderer.js:70]
- **render slot** — the pipeline work for one frame: reconcile, then `frame(alpha)`, then `draw()`. Not: render pass. [src/view/render/pipeline.js:6]
- **light preset** — a named light look (`day`, `dusk`, `night` or custom). Not: preset (alone), time of day. [src/view/render/lights.js:13]
- **object snapshot** — a PNG data URL of one object rendered under a studio light. Not: snapshot (alone), thumbnail, screenshot. [src/view/render/snapshot.js:47]
- **view sync** — the per-frame update of three.js objects from World entities. Not: sync (alone), render sync. [src/view/sync/index.js:41]
- **sync hook** — `sync.on(match, { create, frame, remove })` callbacks. Not: decorator, listener. [src/view/sync/index.js:230]
- **netFix** — `e.netFix = { seq, dp, dq }`, the drawn-pose jump from a net correction. View sync fades it over `smoothMs`. Not: correction offset, smoothing offset. [src/view/sync/smooth.js:10]
- **rig** — a camera controller (chase, mount or orbit). Not: camera controller, cam. [src/view/camera/chase.js:23]

## Netcode

- **transport** — an object `{ isHost, id, hostId, send, on, off, leave }` that emits peer and room events. Not: connection, link, socket. [src/net/transport.js:4]
- **peer** — one page or engine in a room. Not: client, node. [src/net/transport.js:4]
- **host** — the peer with authority over host kinds. The host's sender number is 1. **guest** — any other peer. Not: server, client. [src/sim/replica.js:162]
- **room** — the set of peers on one transport session. Not: lobby, session, match. [src/net/transport.js:69]
- **memory hub** — the in-process star transport with delay, jitter and loss for tests. Not: fake network, mock transport. [src/net/transport.js:13]
- **port** — the object that binds a transport to an engine. Not: adapter, connector. [src/net/port.js:11]
- **peer key** — the random per-tab UUID kept in sessionStorage. Not: client id, session id, token. [src/net/key.js:19]
- **kind** — a declared replicated object type: code, authority, remote mode, fields, send rate, hooks. Not: net type, replicated class, archetype. [src/defs/fields.js:38]
- **field** — a typed field description from `F` (`bool`, `uint`, `id`, `enum`, `fixed`, `angle`, `quat`, `obj`, `list`, `actions`, `body`). Not: property, attribute. [src/defs/fields.js:6]
- **authority** — which peer writes a kind's records: `host` or `owner` (the player whose player number equals the net id). Not: ownership mode. [src/sim/replica.js:162]
- **net id** — an entity's id inside its kind. For owner kinds it equals the owner's player number. Not: replica id, network id. [src/sim/net/install.js:130]
- **record** — one entity's field values for one send. Not: snapshot, state, payload. [src/sim/net/replicate.js:18]
- **replica frame** — a binary message with a header (type, sender, time) and per-kind record and removal groups. Not: frame (alone), packet, snapshot. [src/sim/replica.js:82]
- **keyframe** — a replica frame with every object of an authority. **diff** — a replica frame with only changed objects. Not: full snapshot, delta. [src/sim/replica.js:8]
- **sender** — the device number in a replica frame header. The host is 1. Not: origin, from (in prose). [src/sim/replica.js:101]
- **tracker** — the sender-side change detector that compares encoded record bytes per id. Not: differ. [src/sim/replica.js:122]
- **store** — the receiver-side map of the newest record per kind and id. Not: cache, state store. [src/sim/replica.js:158]
- **replica** — a local entity built from another peer's records through the kind's spawn hook. Not: remote, ghost, proxy (unless remote mode). [src/sim/net/install.js:101]
- **remote mode** — how non-authority peers run a kind: `driven` (real body plus replayed inputs), `proxy` (kinematic body) or `view` (no body). Not: remote type. [src/defs/fields.js:31]
- **follow mode** — how proxy and view replicas move: `interp` or `forecast`. Not: smoothing mode. [src/defs/fields.js:31]
- **interpolation delay** — the render-behind time, 100 ms to 300 ms. Not: buffer delay, lag. [src/sim/interp.js:17]
- **forecast** — a dead-reckoned pose from the newest record's velocity and spin. Not: prediction, extrapolation. [src/sim/forecast.js:13]
- **snap** and **nudge** — the two corrections of a driven replica. A nudge steers velocity over steps. A snap places the body and sets netFix. Not: hard and soft correction. [src/sim/net/remote.js:53]
- **send clock** — the after-step hook that sends replica frames at each kind's `send.hz`. Not: send loop, net tick. [src/sim/net/install.js:612]
- **relay** — the host forwards each guest's newest owner records to the other guests. Not: forward, rebroadcast. [src/sim/net/install.js:218]
- **spawn guard** — the World seam where the net part refuses spawn or despawn of net entities that break kind rules. Not: guard (alone), E-7 check. [src/sim/net/install.js:471]
- **engine join** — the join protocol that the engine owns: `net.hello`, `net.welcome`, `net.refused`, `net.seat`. Not: handshake, login. [src/sim/net/install.js:307]
- **manual join** — `join: 'manual'`: the game sets player numbers through `net.self` and `net.player()`. [src/sim/net/install.js:434]
- **admit** — the host decision for a seat: a player number, `null` (refused `full`) or `{ refuse: reason }`. Not: accept, authorize. [src/sim/net/install.js:336]
- **refusal reason** — why a host refuses a seat: `full`, `seats`, `schema`, `admit`, `busy`, `taken`, or a game reason. Not: error code, deny reason. [src/core/engine.js:24]
- **bindings** — the host map from player number to `{ peer, key, seat }`. Not: assignments. [src/sim/net/install.js:48]
- **locals** — this page's player numbers in the room. **self** — the player number of seat 0. Not: local ids. [src/sim/net/install.js:57]
- **renumber** — a seat's player number changes. The engine emits `player.renumbered`. Not: reassign. [src/sim/net/install.js:294]
- **takeover** — a new page with a matching peer key takes a player from an away peer. Not: steal, hijack. [src/sim/net/install.js:342]
- **schema hash** — an FNV hash of the engine version, kinds and refusal reasons that a join must match. Not: protocol version. [src/core/engine.js:116]
- **wire codec** — the encoder and decoder for tagged commands in `json` or `binary` form. Not: serializer. [src/sim/schema.js:54]
- **rate limit** — at most `perSec` messages per peer in each 1 s window. The port drops extra messages. Not: throttle. [src/sim/limits.js:5]

## Tools and testing

- **game.config.js** — the per-game config file with `id`, `site`, `outEnv`, `bake`, `build` and `test` sections. Not: config (alone), settings. [tools/bake/config.js:42]
- **build stamp** — the `lion-hawk-build` meta tag with game id, game version, engine version and content hash. Not: version tag. [tools/build/page.js:9]
- **dedupe plugin** — the esbuild plugin that resolves three and Rapier from the game root. Not: alias plugin. [tools/dedupe.js:4]
- **headless handle** — the object `h` that `headless()` returns. Not: harness instance, test engine. [testing/headless.js:20]
- **invariant** — a function `(h) => void` that throws on a violation after each headless step. Not: assertion, check (alone). [testing/invariants.js:22]
- **checksum** — the FNV hash (8 hex) of canonical state, used by determinism checks, tapes and golden files. Not: digest (use digest only for the World hash), hash (alone). [testing/state.js:17]
- **golden file** — a stored canonical value plus checksum that fails on change until blessed with `LH_BLESS=1`. Not: snapshot test, fixture. [testing/golden.js:8]
- **tape** — a recording of start options, external ops and per-seat input changes per step, with periodic checksums. Not: recording, replay file, log. [src/core/engine.js:488]
- **blackout** — an `mp()` period in which replica frames are dropped at send. Not: outage, partition. [testing/mp.js:75]
- **device preset** — a Playwright browser profile with viewport, DPR, touch, UA and emulated safe area. Not: preset (alone), device profile. [testing/playwright.js:17]
- **safe area** — screen insets, emulated as `--lh-sa-*` CSS variables. Not: notch insets. [testing/playwright.js:322]
- **game driver** — the in-page driver that `openGame` returns. Not: page fixture. [testing/playwright.js:54]
- **fake pads** — the init script that replaces `navigator.getGamepads` with test-controlled pads. Not: mock gamepads. [testing/playwright.js:269]
- **kit** — an optional per-game module with a sim half and/or a view half, imported as `lion-hawk/kits/<kit>[/view]`. Not: plugin, addon, module (alone). [src/kits/vehicle/sim.js:1]
